# 실제 미디어 수동 회귀 절차

최종 갱신: 2026-07-30 · ffmpegGUI 2.0

자동 하네스는 FFmpeg 인코딩과 결과 프로브를 검증한다. QMediaPlayer 화면,
seek 반응, 사용자 메시지와 앱 종료 상태는 아래 절차로 직접 확인한다.

## 샘플 준비

프로젝트 루트의 PowerShell에서 실행한다.

```powershell
.\.venv\Scripts\python.exe scripts\run_real_media_regression.py
```

샘플은 `artifacts/real_media_regression/samples`에 생성되고 결과는
`artifacts/real_media_regression/report.json`에 저장된다. 테스트 패턴과
1kHz 사인파만 사용하므로 개인정보나 회사 자료는 포함되지 않는다.

## UI 클릭 순서

1. `.\.venv\Scripts\python.exe main.py`로 앱을 연다.
2. `cfr_30fps_audio.mp4`를 파일 목록으로 드래그한다.
3. 항목을 선택하고 미리보기 모드를 켠다.
4. 재생, 일시정지, 타임라인 중간 seek, 0.5x/2x 속도를 순서대로 확인한다.
5. In을 16프레임, Out을 90프레임으로 설정한다.
6. CPU `H.264 Review` 프리셋을 선택하고 인코딩한다.
7. 결과 영상이 재생되고 영상 길이가 약 2.5초인지 확인한다. 오디오는
   스트림·비무음 신호·앱 재생 진행으로 판정한다.
8. 목록을 비우고 `vfr_15_to_30fps.mp4`로 재생·seek·In/Out을 반복한다.
9. `png_sequence/frame.0001.png` 한 장을 드래그해 시퀀스로 인식되는지 확인한다.
10. PNG 시퀀스 재생 중 seek, 마지막 프레임, 다른 영상으로 전환을 확인한다.
11. `animated_12fps.webp`를 추가해 재생과 인코딩을 확인한다.
12. `cancel_source_720p.mp4` 인코딩을 시작하고 진행 중 취소한다.
13. 출력 위치에 불완전 파일이 없고, 작업 관리자에 새 `ffmpeg.exe`가 남지 않는지 확인한다.
14. 영상과 시퀀스를 번갈아 10회 선택한 뒤 앱을 닫는다.
15. 종료 후 앱과 FFmpeg 프로세스가 남지 않는지 확인한다.

## 선택 기준과 판정

- CFR+오디오: 120프레임, 30fps, AAC 오디오 포함
- VFR: 앞 구간 15fps 상당, 뒤 구간 30fps 상당의 타임스탬프 변화
- PNG 시퀀스: 24장, 12fps
- WebP: 24프레임, 12fps 애니메이션
- 취소 샘플: 취소 버튼을 누를 시간을 확보하기 위한 12초 720p 영상

프레임 기반 트림은 기대 프레임 수 대비 ±1프레임을 허용한다. seek는 선택한
프레임 주변으로 이동하고 UI가 멈추지 않아야 한다. 실패 시 샘플명, 클릭 단계,
기대/실제 결과와 `logs`의 최신 로그 파일을 함께 기록한다.
