# 개발 계획

최종 갱신: 2026-08-03

## 0. 시작 기준선

- 기존 `ffmpegGUI v2.0.2` 저장소와 릴리스를 변경하지 않는다.
- 새 프로젝트는 별도 Git 저장소와 빌드 산출물 디렉터리를 사용한다.
- 외부 SDK가 없어도 C++ 편집 코어와 테스트가 빌드되어야 한다.

- [x] C++23/CMake/MSVC 프로젝트
